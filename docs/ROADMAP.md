# Roadmap

| Phase | Objective | Exit criteria |
|---|---|---|
| P0 | Audit and reproduce public baseline | Exact commit, licence inventory, build log and artifact hash |
| P1 | Minimal boot | QEMU boot and serial smoke test |
| P2 | Memory and exceptions | Allocator tests and exception diagnostics |
| P3 | SMP and devices | CPU startup tests and documented device matrix |
| P4 | Inference | Small model loads and generates tokens with repeatable tests |
| P5 | Agent runtime | Capability-denied and resource-limit tests |
| P6 | AgentSON | Schema validation and trace replay |
| P7 | Reliability | Fault-injection report and reproducibility record |
